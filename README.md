# LL(1)-Parser

LL(1) parsing that achieves linear $\mathcal{O}(n) time complexity - that is a simple (possible to automate) approach to transform grammers to a working parser incl semantic tree / evaluation by eliminating left recursive rules.

This repository tracks the practical translation of theoretical computer science concepts into a deterministic, top-down execution engine. Inspired by the academic foundations taught at TU Berlin (Formale Sprachen und Automaten), this project bridges the gap between abstract context-free grammars (CFGs) on paper and actual production-style semantic evaluation in code.
